pressure-monitor ファームウェア書き込みツール

USB で接続した基板（ESP32-C3 + BMP581）に、ブラウザからファームウェアを書き込みます。
対応ブラウザ: パソコンの Chrome / Edge / Opera（Web Serial に対応している必要があります）

1. バージョンを選ぶ

2. 書き込む

  1. 基板を USB-C でパソコンに接続します
  2. 「接続」を押し、表示されたシリアルポート（「USB JTAG/serial debug unit」など）を選びます
  3. 「書き込み開始」を押し、完了するまで待ちます（1 分ほど）
  4. 完了すると、基板が自動で再起動します
ブラウザの対応を確認しています...
[ready] ログを表示します。

うまくいかないとき

  • 接続できない: Arduino IDE のシリアルモニタなど、ポートを使っているほかのアプリを閉じてください。
  • それでも接続できない: 基板の BOOT ボタンを押したまま RESET ボタンを押して離し、BOOT ボタンを離してから（書き込みモード）、もう一度「接続」を押してください。
  • 書き込み後に動かない: RESET ボタンを押してください。
  • USB ケーブル: 充電専用のケーブルでは接続できません。データ通信に対応したケーブルを使ってください。

設定について

通常は、明るさやモードなどの設定は、書き込み後も残ります。 「全消去」に印を付けると、設定も全て消えて、初期値に戻ります（動作がおかしいときに試してください）。

複数台の表示を使う場合

送信の装置とハブは、通信の形式が同じでないと、互いのデータを受け取れません。 全ての装置に、同じバージョンを書き込んでください。
