# BMP581搭載 ESP32-C3 気圧変動可視化開発ボード

![手を動かすと、気圧の変化に応じて LED が青やオレンジに光る様子](../assets/images/esp32c3-bmp581/demo.gif)

Bosch製の高精度気圧センサBMP581を搭載し、気圧の微小な変化を測定して、5個のRGB LEDの光としてリアルタイムに可視化するESP32-C3搭載ボードです。
単三電池ボックスを備えており、単三電池2本で単独動作できます。また、USB-C経由でプログラムを書き換えることができ、汎用のESP32-C3開発ボードとしても利用できます。
さらにQwiicコネクタを搭載しているため、ファームウェアを書き換えることでI²Cセンサなどを追加し、さまざまな環境センシング用途へ拡張できます。

よくあるご質問は、[こちら](faq/)にまとめています。

### 回路の構成

| 部分 | 部品 | 内容 |
|---|---|---|
| マイコン | U2（ESP32-C3-WROOM-02-N4） | RESET ボタン（EN）と BOOT ボタン（IO9） |
| 気圧センサ | U1（BMP581） | I2C、アドレス 0x46（SDO=GND）。SDA は IO4、SCL は IO5 |
| LED | LED1〜LED5（WS2812B-V6） | データは IO10 から R8 330Ω を通して LED1 へ。5 個がデイジーチェーン |
| USB | USB1（USB-C）、U5（HT7833） | VBUS を 3.3V にする。D-/D+ は IO18/IO19 |
| 電池 | U4（TPS61291）、単三 2 本 | 昇圧して 3.3V にする |
| 電源の切り替え | SW1 | 3V3 を、電池（BAT_3V3）と USB（USB_3V3）のどちらから取るかを選ぶスライドスイッチ |
| 電池電圧 | R9、R10、C12 | 電池電圧を 1/2 に分圧して IO1 へ（ADC で読める） |
| Qwiic | Qwiic コネクタ | I2C バス（3V3、SDA、SCL）に接続。他の I2C 機器をつなげる |

## 使い方

### 表示の見かた

| LED | 意味 |
|---|---|
| LED1 | 今の気圧の変化 |
| LED2〜LED5 | 1 フレームごとに前の LED1 の色が流れていく |

| 色 | 意味 |
|---|---|
| 青 | 気圧が上がった（センサを下げた） |
| オレンジ | 気圧が下がった（センサを持ち上げた） |
| 明るさ | 変化が大きいほど明るく、最大で白 |
| 消灯 | 変化がごくわずか |

気圧そのものではなく、ハイパスフィルタで取り出した「変化」を表示します。センサを動かさなければ、しばらくすると消灯します。

### 表示モード

BOOT ボタンを短く押して、4 種類のモードを切り替えます。

| 番号 | モード | 内容 |
|---|---|---|
| 1 | 標準（既定） | 気圧の変化を表示する。細かい動き向け |
| 2 | ドライブ | 気圧の変化を表示する。車や電車での移動（大きな高さの変化）向け |
| 3 | カスタム | 気圧の変化を表示する。感度をスマホから変更できる |
| 4 | 固定色 | 全ての LED が、同じ色（HSV で自由に設定）で点灯する |

LED の明るさの最大値は、1〜3 で共通の設定です。標準とドライブは、明るさの最大値だけを設定できます。

### ボタン

BOOT ボタンは、どちらの操作も、ボタンを離したときに動作します。

| 操作 | 動作 |
|---|---|
| 短押し | 今のモードの番号の数だけ、LED が 2 秒間、青く点灯する。その間に続けて押すと、次のモードに切り替わる（4 の次は 1） |
| 長押し（1.5 秒以上） | 設定モードと通常モードを切り替える |

たとえば、モード 2（ドライブ）のときに押すと、LED1 と LED2 が青く点灯します。2 秒以内にもう一度押すと、モード 3（カスタム）になり、LED1〜LED3 が青く点灯します。選んだモードは、電源を切っても残ります。

### 設定モード

長押しして離すと、基板が Wi-Fi のアクセスポイントになり、スマホから明るさ、カスタムモードの感度、固定色などの設定を変更できます。

1. 基板の BOOT ボタンを、LED が水色になるまで（1.5 秒以上）長押しして、離します
2. スマホの Wi-Fi で、SSID `pressure-monitor`（パスワードなし）に接続します
3. ブラウザで `http://192.168.4.1/` を開きます（QR コードを読み取ると便利です。Android では、「ネットワークへのログインが必要です」という通知が出ることがあります）。値を変えると、LED にすぐ反映されます。気に入った設定は、「保存」を押して保存します（保存しないまま再起動すると、元の値に戻ります）
4. 「保存して終了」を押すと、Wi-Fi がオフになり、通常モードに戻ります

設定モードの間は、LED5 が状態表示になります（暗い水色は接続待ち、緑は接続中）。操作がないまま 10 分たつと、自動で通常モードに戻ります。変更できる項目や、詳しい使い方は、[firmware の README](https://github.com/ksasao/pressure-monitor/tree/main/firmware/esp32c3-bmp581#設定モードwi-fi)をご覧ください。

### 電源

単三電池 2 本、または USB-C から給電できます。SW1 で切り替えます。

**USB-C にモバイルバッテリーをつなぐ場合は、「低電流モード」（微弱電流モード、IoT モードなどの名称）に対応した製品を推奨します。** モバイルバッテリーの多くは、出力電流が小さい状態が続くと、負荷がつながっていないとみなして、出力を止めます。本機は、LED が消えているとき、省電力のために電流が約 1mA まで下がるので、低電流モードに対応していない製品では、数分で給電が止まることがあります。

## 制約

- 電池と USB のどちらで動いているかは、回路の構成上、ソフトウェアでは判別できません。
- 電池電圧は IO1 で読むことができます。ファームウェアは、1 分に 1 回測り、シリアルの CSV の最後の列に出力します。
- BMP581 は温度補正済みの気圧を出力します。起動直後は、センサの自己発熱で温度が上がり続けますが、ハイパスフィルタがゆっくりした変化を除くので、表示への影響は小さいです。
