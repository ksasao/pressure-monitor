# クイックスタート

[esp32c3-bmp581 のページへ戻る](../)

届いた基板で、基本の操作をひととおり試すための手順です。5 分ほどで終わります。

## 用意するもの

| もの | 内容 |
|---|---|
| 本体基板 | |
| 単三電池 2 本 | アルカリ電池でも、ニッケル水素電池（エネループなど）でも使えます。電池の代わりに、USB-C で給電することもできます |
| スマホ | 手順 5 で使います（なくても、手順 1〜4 は試せます） |

## 1. 電源を入れる

1. 裏面の電池ボックスに、単三電池 2 本を入れます（向きに注意してください）
2. 表面の電源スイッチ（SW1）を ON にします

全ての LED が白く光り、続いて赤 → 緑 → 青の順に光ったら、起動しています。そのあと、LED は消えます（気圧が変わっていないため）。

USB-C で給電するときは、USB-C ケーブルをつなぐだけで起動します。

## 2. 持ち上げて下ろしてみる

基板を机の上から、**10 cm ほど、すっと持ち上げて**みてください。LED が**オレンジ**に光ります。持ち上げたまま止めると、数秒で消えます。

次に、**元の高さまで下ろす**と、今度は**青**に光ります。

| 動かし方 | LED |
|---|---|
| 持ち上げる（気圧が下がる） | オレンジ |
| 下ろす（気圧が上がる） | 青 |
| 大きく、速く動かす | 明るくなり、最大で白 |
| 止める | 数秒で消える |

1 Pa の気圧の差は、高さ約 8.5 cm の差です。机から床へ下ろしたり、階段を上ったりすると、はっきり光ります。光の色は LED1 に出て、後ろの LED へ流れていきます。

**ほかにも試せること:** 部屋のドアを勢いよく開け閉めすると、部屋の気圧がわずかに変わって、LED が光ることがあります。

## 3. 表示モードを変えてみる

BOOT ボタンを**短く押す**と、今のモードの番号の数だけ、LED が 2 秒間、青く光ります。光っている間に、もう一度押すと、次のモードに変わります。

| 青く光る数 | モード | 向いている使い方 |
|---|---|---|
| 1 個 | 標準（最初はこれ） | 手で持ち上げるなど、細かい動き |
| 2 個 | ドライブ | 車、電車、エレベーターなど、大きな高さの変化 |
| 3 個 | カスタム | 感度をスマホで変えて使う |
| 4 個 | 固定色 | 全ての LED を、好きな色で光らせる |

選んだモードは、電源を切っても残ります。標準に戻すときは、1 個だけ光るまで押してください。

## 4. 持ち歩いてみる

ドライブモードにして、持ち歩いてみてください。エレベーターや階段、電車での移動で、色が変わります。新幹線がトンネルに出入りするときの大きな変化も、色の違いで見分けられます。新幹線のそばで記録した例は、[ギャラリー](../gallery/)にあります。

## 5. スマホで気圧を見る（設定モード）

1. BOOT ボタンを、LED が**水色**になるまで（1.5 秒以上）**長押し**して、離します
2. スマホの Wi-Fi で、`pressure-monitor`（パスワードなし）に接続します
3. 気圧の表示のページが、自動で開きます。開かないときは、ブラウザで `http://192.168.4.1/` を開きます

気圧の値と変化のグラフが表示されます。基板を持ち上げたり下ろしたりすると、グラフが動きます。右上の「⚙ 設定」から、LED の明るさなどを変えられます。

終わったら、設定のページの「保存して終了」を押すか、BOOT ボタンをもう一度長押しして離すと、元の表示（通常モード）に戻ります。ページを閉じて 10 分たったときも、自動で戻ります。

## 6. 記録してみる

5 の設定モードの最初のページで、「● 記録」を押すと、気圧を基板の中に記録できます。あとから、同じページの「CSV 保存」で、スマホに保存できます。間隔は、1/30 秒（約 16 時間分）、1 秒（約 68 時間分）、30 秒（約 84 日分）から選べます。

## うまくいかないとき

| 起きていること | 試すこと |
|---|---|
| 電源を入れても、何も光らない | 電池の向きと、SW1 が ON になっているかを確かめます。電池が弱いと、起動しないことがあります |
| 持ち上げても光らない | 標準モード（1 個）になっているかを確かめます。ゆっくり動かすと、変化が小さく、光りにくくなります。すっと動かしてください |
| ずっとちらちら光る | 風や空調で、部屋の気圧が揺らいでいます。故障ではありません |
| 設定を最初に戻したい | BOOT ボタンを 20 秒押し続けると、全ての LED が赤く点滅したあと、設定が全て初期値に戻ります |

ほかの使い方は、[esp32c3-bmp581 のページ](../#使い方)と、[よくある質問](../faq/)をご覧ください。
