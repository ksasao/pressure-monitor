# firmware / esp32c3-bmp581

ESP32-C3 + BMP581 + WS2812B × 5 のファームウェア（Arduino スケッチ）です。

スケッチ: [`esp32c3-bmp581.ino`](esp32c3-bmp581.ino)

## 必要なもの

| 項目 | 内容 |
|---|---|
| 開発環境 | Arduino IDE 2.x |
| ボードパッケージ | ESP32（Espressif Systems 製、ESP32-C3 に対応した版） |
| ライブラリ | **SparkFun BMP581 Arduino Library** / **FastLED**（3.7.0 以降） |

## ボード設定

| 設定 | 値 |
|---|---|
| Board | ESP32C3 Dev Module |
| USB CDC On Boot | **Enabled**（Disabled だと Serial が出ません） |

書き込みは USB-C から行います。認識されないときは、BOOT ボタンを押しながら RESET ボタンを押すと、書き込みモードに入ります。

## ピン割り当て

| 機能 | GPIO | 備考 |
|---|---|---|
| I2C SDA | 4 | BMP581 SDI（プルアップ 4.7kΩ） |
| I2C SCL | 5 | BMP581 SCK（プルアップ 4.7kΩ） |
| LED データ | 10 | R8 330Ω 経由で LED1 の DIN |
| BOOT ボタン | 9 | 表示モードの切り替えにも使う（active low） |
| USB D- / D+ | 18 / 19 | ネイティブ USB（Serial） |
| 電池電圧 | 1 | R9/R10（各 1MΩ）で 1/2 に分圧。ADC で読み、1 分に 1 回シリアルに出力 |

BMP581 の I2C アドレスは SDO を GND に接続しているので **0x46** です。見つからなければ 0x47 も試します。

## 動作

約 30Hz（33ms 周期）でセンサを読み、LED を更新します。

1. 気圧を整数のまま、1 次ハイパスフィルタに通す（ゆっくりした変化は消える）
2. 変化量の絶対値が `DELTA_LIMIT` 未満なら消灯
3. それ以上なら、変化の向きに応じたパレットで色にする
   - 気圧上昇: 黒青 → 青 → 水色 → 白
   - 気圧下降: 黒赤 → オレンジ → 黄橙 → 白
4. 毎フレーム、色を 1 つずつ後ろの LED へ送る（LED1 が最新）

BOOT ボタンで表示モードが切り替わります。

| モード | 表示 |
|---|---|
| 0（起動時） | 気圧の変化（上記） |
| 1 | 気圧の絶対値を 5 段階のバーで表示（低圧=青 → 高圧=赤） |
| 2 | 消灯 |

## シリアル出力

115200bps の CSV です。毎ティック 1 行出ます。

```
millis,pressure_hPa,raw,hpf,temperature_C,altitude_m,led_value
```

| 列 | 内容 |
|---|---|
| `raw` | 気圧の値（1 LSB = 1/64 Pa）。BMP581 の内蔵温度補正済みの値です |
| `hpf` | ハイパスフィルタの出力（同じ単位）。符号が正なら気圧上昇 |
| `led_value` | LED1 の RGB の最大値 |

`#` で始まる行はメッセージです。1 秒ごとに `# perf` の行が出て、処理時間やログの取りこぼしを確認できます。

電池電圧は、起動時と、その後 1 分に 1 回、次の形式で出力します。

```
# battery 2.874 V
```

電池が入っていないとき（USB 給電中など）は、末尾に `(not installed)` が付きます。ADC の誤差は数 % あるので、正確な値が必要なときは、テスターの実測と突き合わせてください。

## 調整できるパラメータ

スケッチ冒頭の定数です。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `DELTA_LIMIT` | 50 | この変化量（1/64 Pa 単位）未満は消灯。約 0.78 Pa、高さで約 6.6cm |
| `DELTA_RANGE` | 400 | この変化量で白になる。約 6.25 Pa、高さで約 53cm。広い範囲を見るなら 15000（約 20m） |
| `FILTER_STRENGTH_SHIFT` | 8 | ハイパスフィルタの時定数。約 2^n サンプル（30Hz で n=8 なら約 8.5 秒）。大きいほどゆっくりした変化まで拾う |
| `TRAIL_STEP_TICKS` | 1 | 色を後ろへ送る間隔（ティック数）。大きくすると、LED2〜5 に長い時間の履歴が流れる |
| `TICK_INTERVAL_MS` | 33 | 更新周期（約 30Hz） |
| `CPU_MHZ` | 40 | CPU クロック。下げるほど消費電力が減る |
| `LOG_EVERY_N` | 1 | ログを何ティックに 1 回出すか |
| `BATTERY_INTERVAL_MS` | 60000 | 電池電圧を出力する間隔（ミリ秒） |
| `PWR_MILLIAMPS` | 250 | LED の電流上限（FastLED が自動で輝度を抑える） |
| `BAR_MIN_HPA` / `BAR_MAX_HPA` | 995 / 1025 | モード 1 の表示範囲（hPa） |

感度は、BMP581 の静止時のノイズ（`hpf` の振れ幅）に合わせて決めます。ログの `hpf` 列を見て、`DELTA_LIMIT` が振れ幅より十分大きいか確認してください。

## トラブルシューティング

**LED が白のまま変化しない**
Adafruit_NeoPixel と ESP32 のボードパッケージの組み合わせで、全点灯のまま固まることがありました。このスケッチは FastLED を使っています。FastLED は 3.7.0 以降を使ってください。それでもだめなら、`#include <FastLED.h>` の前に `#define FASTLED_RMT5 0` を置くと直ることがあります。

**BMP581 が見つからない**
起動時に I2C のスキャン結果が出ます。何も見つからなければ、SDA/SCL の配線、3V3、プルアップ、BMP581 のはんだ付けを確認してください。見つかるのに初期化できないときは、CSB が VDDIO にプルアップされているか確認してください（GND だと SPI モードになり、I2C から見えません）。

**コンパイルエラーになる**
`BMP5_ODR_50_HZ` や `BMP5_OVERSAMPLING_*` のマクロ名は、ライブラリのバージョンで異なることがあります。ライブラリの `bmp5_defs.h` で名前を確認してください。`Serial.setTxTimeoutMs()` は、USB CDC On Boot を Enabled にしたときだけ使えます。

**シリアルモニタを開くと基板がリセットされる**
ESP32-C3 のネイティブ USB の通常の動作です。

**シリアルモニタのログが止まる**
Arduino IDE のシリアルモニタで、自動スクロールをオフにしたときなどにログが止まることがありました（原因は未特定）。LED の動作には影響しません。ログを確実に見たいときは、Tera Term などの別のターミナルを使うか、`LOG_EVERY_N` を大きくしてください。

## 補足

- BMP581 は温度補正を内蔵していて、気圧レジスタは補正済みの値です。
- 起動直後は、センサの自己発熱で温度が上がり続けます。ハイパスフィルタがゆっくりした変化を除くので、表示への影響は小さいです。
